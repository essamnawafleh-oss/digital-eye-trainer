## Where the data is

| Location | Contains | Share? |
|---|---|---|
| `workspace/labels.sqlite` | line labels, original file names (to find a document again) | **never** |
| `workspace/crops/` | line images cut from your documents | **never** |
| `workspace/datasets/` | lists of labelled lines for training | **never** |
| `workspace/runs/` | training checkpoints (model weights) | **never** |
| `workspace/exports/` | the fine-tuned model for Digital Eye | **never** (confidential, see below) |
| `workspace/private/` | per-line before/after text of test errors | **never** |
| `workspace/reports/` | evaluation reports: counts and rates only | yes |
| `workspace/runs/*/progress.json`, `data_summary.json` | step counts, error rates, line counts, unsupported characters as code points (`U+2603`) | yes |

Document IDs are the first 16 hex digits of each file's SHA-256: they identify a file to
you but reveal nothing about its content. Report files never contain IDs, file names,
text or images (tested in `tests/test_pipeline.py::test_reports_contain_no_document_text`).

## What is enforced

1. **Offline guard** around import, labelling server, training, evaluation and export
   (`eye_trainer/offline.py`): blocks non-loopback connections, DNS lookups and UDP sends in
   the process; removes proxy variables; blocks loopback ports of configured proxies; sets
   `HF_HUB_OFFLINE`, `PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK` and telemetry opt-outs.
2. **System-level test** (Linux): the full pipeline runs inside `unshare -rn` (a network
   namespace with no interfaces). `scripts/verify_offline.sh <command>` runs any command that way.
   On Windows, unplug the network / disable Wi-Fi to get the same guarantee.
3. **Local page**: bound to `127.0.0.1`, foreign `Host` headers refused, per-session token,
   strict Content-Security-Policy, no external resources.
4. **No telemetry.** The only network code in the tool is `download-models`.

What the guard cannot do: it protects this tool's own process. It does not stop *other*
programs on your computer (cloud backup or sync folders, antivirus "cloud scanning").
Keep `workspace/` outside synced folders (OneDrive, Google Drive, Dropbox, iCloud).

## The fine-tuned model is confidential

Neural text recognisers can memorise strings that occur often in their training data:
owner names, plot and permit numbers, stamps. Someone holding the model could, in principle,
probe it to recover some of these. Therefore:

* store exported models like the documents themselves;
* do not upload, e-mail or publish them, or send them to cloud services;
* when sharing results, share only `workspace/reports/`.

Each export contains a `CONFIDENTIAL.txt` that repeats this warning.

## Synthetic data and development

All development and all automated tests used synthetic data generated by the tool. No real
document was seen during development. The fonts used for synthetic lines are bundled
(SIL OFL); you can add your own fonts to `workspace/fonts/`.
